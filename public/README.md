# 📖 Aesthetic Digital Diary

A custom, web-based digital diary application featuring a realistic notebook design and multi-page entry tracking. Built using pure HTML, CSS, and Vanilla JavaScript.

## 🌟 Features
- **Notebook Layout:** Clean, aesthetic paper background and custom typography.
- **Multi-Page Entry:** Write long-form entries split across multiple pages using array storage.
- **Dynamic Controls:** Flip through previous and next pages using interactive buttons.
- **Responsive UI:** Custom styled controls, date inputs, and floating page elements.

## 🛠️ Built With
- **HTML5** - Page structure and form elements
- **CSS3** - Layout styling, custom fonts, and aesthetic design
- **JavaScript (Vanilla)** - DOM manipulation, event listeners, and dynamic array indexing

## 🗺️ Roadmap

## 💻 How to Run Locally
1. Clone or download this repository.
2. Open `index.html` (or `diary.html`) directly in your browser, or run it using VS Code's **Live Server** extension.
